## Deskripsi Proyek

Proyek ini bertujuan membandingkan pendekatan *instance-based learning* (KNN) dan *tree-based learning* (Decision Tree) pada kasus evaluasi kelayakan kendaraan. Mahasiswa diharapkan mampu menginterpretasikan dampak representasi kategori dan hiperparameter, serta menganalisis perbedaan hasil prediksi kedua model.

## Dataset

**UCI Car Evaluation Database**
🔗 https://archive.ics.uci.edu/dataset/19/car+evaluation

Dataset berisi 1.728 baris dengan 6 atribut kategorikal (`buying`, `maint`, `doors`, `persons`, `lug_boot`, `safety`) dan 1 label target (`class`: unacc, acc, good, vgood). Atribut bersifat kategorikal sehingga kode angka tidak boleh otomatis dianggap sebagai jarak yang bermakna.
